# Terraforming Mars VP Predictor

A machine learning web application for predicting Victory Points (VP) in Terraforming Mars based on selected corporation and cards.

## Features

- **VP Prediction**: Select a corporation and cards to get a predicted VP score
- **Automatic Model Training**: Model is automatically trained on deployment if not present
- **Modern UI**: Beautiful, responsive web interface
- **RESTful API**: FastAPI backend with comprehensive endpoints

## Quick Start

### Local Development

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Train the model (first time):**
   ```bash
   python scripts/train_model.py
   ```
   This creates `web/model.pkl` which will be used by the web app.

3. **Run the server:**
   ```bash
   python web/run_server.py
   ```

4. **Open your browser:**
   Navigate to `http://localhost:8000`

### Updating the Model

To retrain the model with new data or different parameters:

1. **Train locally:**
   ```bash
   python scripts/train_model.py
   # Or with custom parameters:
   python scripts/train_model.py --n-estimators 800 --min-samples-leaf 3
   ```

2. **Commit the new model:**
   ```bash
   git add web/model.pkl
   git commit -m "Update model"
   git push
   ```

3. **Deploy** (if using cloud platform, it will auto-deploy)

The model file (`web/model.pkl`) should be committed to the repository so it's available on deployment.

## API Endpoints

- `GET /` - Frontend web interface
- `GET /cards` - List all available cards
- `GET /corporations` - List all available corporations
- `POST /predict` - Predict VP (requires corporation and cards)
- `GET /model/status` - Check if model is loaded

## Model Training

The model is trained using RandomForestRegressor with the following default parameters:
- `n_estimators=600`
- `min_samples_leaf=2`
- `random_state=42`

To customize training, edit `scripts/train_model.py` or use command-line arguments:

```bash
python scripts/train_model.py --n-estimators 800 --min-samples-leaf 3
```

## Notes

- The model uses RandomForest by default
- Card and corporation names are case-insensitive
- Model training is done locally via script, not through the web interface
- The model file should be committed to the repository for deployment
