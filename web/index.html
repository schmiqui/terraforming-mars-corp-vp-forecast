Project Overview

This interactive web application uses machine learning to predict Victory Points (VP) in the board game Terraforming Mars based on the corporation a player chooses and the cards they start with. Players select their corporation and initial cards, and the app estimates their final score using historical game data. The goal is to help players decide which corporation best fits their opening hand, while also analyzing how strongly corporation choice and early card selection influence the total score.

The prediction model was trained on real game data, analyzing patterns between card combinations, corporation choices, and final victory point totals to help players make more informed decisions during gameplay.

Methods & Machine Learning Approach

Feature Engineering

The model uses the following features extracted from selected cards and corporation:

  • Card Tags: Building, Jovian, Power, Science, City, Event, Space, Earth, Plant, Animal, Microbe
  • Total VP from Cards: Sum of victory points provided by selected cards
  • Total Price: Combined cost of all selected cards
  • Corporation: One-hot encoded corporation selection

Model Architecture

The application uses a Linear Regression model with the following preprocessing pipeline:

  • Numerical Features: Median imputation + StandardScaler normalization
  • Categorical Features (Corporation): Most frequent imputation + OneHotEncoder
  • Data Splitting: GroupShuffleSplit (80/20) to preserve game groups, preventing data leakage

Model Training

The model is trained using scikit-learn's LinearRegression with default parameters. The training process:

  1. Loads game data from CSV format
  2. Extracts features from card tags, VP, price, and corporation
  3. Splits data into training (80%) and test (20%) sets using GroupShuffleSplit
  4. Applies preprocessing pipeline (imputation, scaling, encoding)
  5. Trains the linear regression model
  6. Evaluates performance using R² score, MAE, and RMSE metrics

Explanation

We evaluated several regression models (including Lasso and related approaches), but their performance was very similar. This outcome suggests that the corporation choice and the initial card set are only weak predictors of the final Victory Points. In practice, much stronger predictors would include information that becomes available later in the game—such as awards and milestones, the number of generations, and the amount of cities, greenery, and other board development. However, the goal of this project was to support decision-making at the very start of the game, when these attributes are still unknown. This also highlights the complexity of Terraforming Mars, where many mid- and late-game decisions significantly influence the final score. Another limiting factor was data availability: our dataset contained approximately 1500 records, which is relatively small compared to the large number of unique cards in the game. For this reason, we represented cards using aggregated tag counts rather than relying only on individual card names.

Future

- In the future, we would like to implement an algorithm that computes the best combination of corporation and starting cards (by running multiple prediction calls).
- We would like to add more in-game features (e.g., milestones/awards, number of generations, cities, greenery, plants, and other board metrics) to improve prediction accuracy.
- We would like to expand the dataset with more recorded games to make the model more robust and reliable.

Dataset Creation

The dataset was created through a multi-step process:

Step 1: Raw Data Collection

Game data was collected from actual Terraforming Mars game sessions, stored in JSON format containing:

  • Game Dictionary (gamedict): Contains final victory point totals for each game
  • Log Dictionary (logdict): Contains game logs with corporation selections and card purchases

Note: Available at: https://github.com/RuneDK93/terraforming-mars-dataset.git

Step 2: Data Parsing

The parse_dataset.py script processes the raw JSON data:

  • VP Extraction: Parses the game dictionary to extract final VP totals for each game
  • Corporation Extraction: Parses log text to find lines starting with "You choose corporation"
  • Card Extraction: Parses log text to find all lines starting with "You buy" (card purchases)
  • Merging: Combines VP totals with corporation and card data by matching game_id

Step 3: Feature Extraction

The tm_card_score.py script processes the parsed games:

  • Card Lookup: Matches card names from games to card definitions in cards.json
  • Tag Counting: Counts occurrences of each tag type (building, space, science, etc.)
  • VP Summation: Calculates total VP from all selected cards
  • Price Summation: Calculates total cost of all selected cards
  • Corporation Normalization: Normalizes corporation names to lowercase

Step 4: CSV Export

The processed data is exported to CSV format with columns:

  • game_id - Unique game identifier
  • points - Final victory points (target variable)
  • building, jovian, power, science, city, event, space, earth, plant, animal, microbe - Tag counts
  • totalVp - Sum of VP from cards
  • totalPrice - Sum of card costs
  • corporation - Selected corporation name

Data Sources
